# Diversification Under Stress

**Empirical Evidence of Correlation Breakdown Across Sectors and International Markets**

Fabio Trachsler — ETH Zürich · `ftrachsler@student.ethz.ch`

Working paper · May 2026 · SSRN: [link to be added]

---

## Abstract

Using daily return data from 1999 to 2025 spanning ten U.S. sector ETFs and eight international equity indices, this paper documents a systematic correlation breakdown during crisis episodes: mean pairwise correlations rise in **71.2%** of all stress events, with a mean Δρ = 0.094 (p < 0.0001). The paper introduces the **Trachsler Resilience Score**, a formal criterion for constructing stress-robust portfolios, validated out-of-sample across 18 independent stress events (drawdown advantage significant at p = 0.003).

## Data

All data are retrieved from Yahoo Finance via the `yfinance` Python library. To reproduce the Parquet files, run the data download block at the top of `analysis.py`. No data files are included in this repository.

**Sector panel (1999–2025):** XLK, XLF, XLV, XLE, XLI, XLY, XLP, XLU, XLB, IYR

**International panel (2003–2025):** SPY, IEV, EWJ, EEM, EWU, EWG, EWZ, EPP

## Reproducing the Paper

Run scripts in the following order:

```bash
python analysis.py          # Figures 1–7
python mini_crises.py       # Figures 8–10
python stress_scan.py       # Figures 11–12
python resilience_score.py  # Figures 13–14
python backtest.py          # Figures 15–18
python oos_validation.py    # Figures 19–20
```

All figures are saved as high-resolution PNG files to `plots/`. CSV outputs go to `output/`.

## Key Results

| Finding | Value |
|---------|-------|
| Stress events with correlation breakdown | 71.2% (42/59) |
| Mean Δρ across all stress events | +0.094 (p < 0.0001) |
| Highest single Δρ (Trump Tariff Shock, April 2025) | +0.379 |
| Resilience Portfolio drawdown win rate (out-of-sample) | 83% (15/18, p = 0.003) |
| COVID crash sector Δρ | +0.282 |
| Flash Crash: sector vs. international Δρ gap | 0.180 |
